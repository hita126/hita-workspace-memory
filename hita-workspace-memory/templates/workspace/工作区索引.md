## 用法

agent 接到任务时先读这一页：按项目名、触发词或原始路径找到项目，再去读它的 `项目卡.md`。

## 目录

- `memory/`：跨项目的通用规则、用户偏好、长期决策、纠错反馈。
- `projects/`：一个项目一个文件夹，每个文件夹五个文件。
- `templates/`：可复用的模板（报告、周报……）。
- `scripts/`：可复用的脚本。
